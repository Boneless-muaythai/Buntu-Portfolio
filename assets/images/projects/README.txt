PROJECT IMAGES
==============

Drop your real project screenshots in this folder using these exact filenames
so they appear automatically on the site (Projects section of index.html):

  project-1.jpg   -> first project card
  project-2.jpg   -> second project card
  project-3.jpg   -> third project card

Recommended specs
-----------------
- Aspect ratio : 4:3 (the cards are cropped to 4:3)
- Size         : ~1200 x 900 px
- Format       : .jpg (photos/screenshots) or .webp for smaller files
- File weight  : keep under ~300 KB each for fast loading

If a file is missing, the card shows a clean branded gradient instead of a
broken image, so the page always looks intentional while you gather assets.

Want different filenames or more than 3 projects? Update the <img src="...">
paths in the Projects section of index.html to match.
